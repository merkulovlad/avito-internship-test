# Запуск 
- Проект запускает **docker-compose up** командой.
- Для запуска нагрузочного тестирования(контейнер должен быть поднят во время тестирования)
``` bash

./run_all.sh
```

### Тест 1: Статистический эндпоинт (GET /stats/assignments)

#### Описание
Тестирование read-only эндпоинта получения статистики по назначениям ревьюеров.

#### Профиль нагрузки
- **Разгон:** 0 → 10 VUs за 10 секунд
- **Основная нагрузка:** 10 → 50 VUs за 30 секунд
- **Спад:** 50 → 0 VUs за 10 секунд
- **Общая длительность:** 50 секунд

#### Результаты
```
✓ Все проверки пройдены: 100%
✓ HTTP статус 200: 100%
✓ Время ответа (p95): < 300 мс
✓ Процент ошибок: 0%
```

#### Ключевые метрики
| Метрика | Значение | Норма |
|---------|----------|-------|
| Время ответа (среднее) | ~15-20 мс | < 300 мс |
| Время ответа (p95) | < 25 мс | < 300 мс |
| Успешность запросов | 100% | > 99.9% |
| RPS | ~40-50 | > 5 |

**Вывод:** Эндпоинт статистики показывает отличную производительность даже при 50 одновременных пользователях.

### Тест 2: Создание Pull Request (POST /pullRequest/create)

#### Описание
Тестирование write-heavy эндпоинта создания PR с автоматическим назначением до 2 ревьюеров из команды автора.

#### Профиль нагрузки
- **Разгон:** 0 → 5 VUs за 10 секунд
- **Основная нагрузка:** 5 → 20 VUs за 30 секунд
- **Спад:** 20 → 0 VUs за 10 секунд
- **Общая длительность:** 50 секунд

#### Результаты

##### Пороги (Thresholds)
```

✓ http_req_duration.....: p(95) < 300ms  (фактически: 11.14ms)
✓ http_req_failed.......: rate < 0.05    (фактически: 0.00%)
```

##### Проверки (Checks)
```
Всего проверок.......: 9,516
Успешных.............: 9,516 (100.00%)
Неудачных............: 0 (0.00%)

✓ status is 201 or 409.....: 100%
✓ status is 201 (created)..: 100%
✓ response has body........: 100%
✓ content type is JSON.....: 100%
```

##### Пользовательские метрики
```

```

##### HTTP метрики

| **Время ответа (med)** | 3.9 мс | Медианное время |
| **Время ответа (min)** | 1.39 мс | Минимальное время |

| **Время ответа (p95)** | **11.14 мс** | **95% запросов быстрее** |

#### Анализ результатов

   - 95-й перцентиль времени ответа составляет всего **11.14 мс** при требовании < 300 мс
   - Это означает запас производительности в **27 раз** (300/11.14 ≈ 26.93)

   - 100% успешных запросов (2379 из 2379)
   - 0% ошибок при любых проверках
   - Полное соответствие SLI успешности 99.9%

   - Фактический RPS: **47.51** при требовании > 5
   - Создано **2,379 PR** за 50 секунд
   - Запас по пропускной способности: **9.5 раз** (47.51/5 ≈ 9.5)

   - Медиана (3.9 мс) близка к среднему (6.06 мс)
   - Максимальное время (178.48 мс) значительно ниже порога
   - Стабильная производительность даже при пиковой нагрузке (20 VUs)

   - Все PR созданы с корректными JSON-ответами
   - Автоматическое назначение ревьюеров работает без сбоев
   - Правильная обработка всех запросов (статус 201)
